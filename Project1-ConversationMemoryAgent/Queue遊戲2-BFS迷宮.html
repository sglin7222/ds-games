一行程式碼的差別

frontier = [start] seen = {start} parent = {} while frontier: cur = frontier.popleft() # ← Queue：拿最早放進去的 → BFS cur = frontier.pop() # ← Stack：拿最晚放進去的 → DFS if cur == goal: break for nb in neighbors(cur): if nb not in seen and not is_wall(nb): seen.add(nb) parent[nb] = cur frontier.append(nb)
整份程式碼一模一樣，只有取出元素的那一行不同。
popleft()（Queue，FIFO）→ 一圈一圈往外擴散 → 保證找到最短路徑
pop()（Stack，LIFO）→ 一路衝到底再回頭 → 會找到路，但通常不是最短的

📦 Queue（BFS 廣度優先）

  • 像水波紋，均勻地一圈一圈擴散
  • 保證最短路徑（每格權重相同時）
  • 記憶體用量大：要存整圈的邊界
  • 用途：最短路徑、社群網路「幾度分隔」、西洋棋馬走日最少步數

🥞 Stack（DFS 深度優先）

  • 像一條蛇，一路鑽到底再回頭
  • 不保證最短，可能繞很大一圈
  • 記憶體用量小：只存一條路徑
  • 用途：找出「有沒有路」、拓撲排序、解數獨、迷宮生成
比較項目Queue（BFS）Stack（DFS）
取出的元素最早放進去的（FIFO）最晚放進去的（LIFO）
擴散形狀圓形波紋細長蛇形
最短路徑✅ 保證❌ 不保證
時間複雜度O(V + E)O(V + E)
空間複雜度O(最寬那一層)O(最深那條路)
