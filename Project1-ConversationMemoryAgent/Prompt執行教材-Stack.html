第 1 天：理解 Stack 是什麼

📚 Prompt 1：理解 Stack
✂️ 複製下面的 Prompt 發給 Claude：
你是資料結構講師。用簡單的例子解釋 Stack。 不要講 Python 語法，講： - 為什麼叫「棧」？真實生活的例子？ - 什麼時候用 Stack 而不是列表？ - Stack 最重要的性質是什麼（LIFO）？ - 給我 3 個日常生活中 Stack 的例子 用日常語言，不要用術語。
✅ Claude 的回答（部分）：
Stack（棧）就像一個裝盤子的架子： - 你把盤子一個一個疊起來 - 要拿盤子時，只能從最上面拿 - 最後放上去的盤子，最先被拿下來 - 這就叫「後進先出」（LIFO） 日常例子： 1️⃣ 自助餐的盤子架 - 放上去的盤子最後拿 2️⃣ 瀏覽器的返回按鈕 - 最後進的網頁，最先返回 3️⃣ 撤銷/重做功能 - Ctrl+Z 撤回最後一步編輯 4️⃣ 函數調用棧 - 最後調用的函數最先結束
ℹ️ 學生現在理解了： Stack 是什麼，為什麼重要，什麼時候用

第 3 天：實現 Stack

💻 Prompt 3：實現 Stack 類
✂️ 複製下面的 Prompt：
用 Python 實現一個 Stack 類。 需求： - 方法：push、pop、peek、is_empty、size - push/pop 時間複雜度必須是 O(1) - 內部用 list 存儲 - 每個方法都有文檔字符串 - 邊界情況：空棧時 pop 和 peek 返回 None 給我完整可運行的代碼。
✅ Claude 給出的代碼：
class Stack: def __init__(self): self._items = [] def push(self, item): """將元素添加到棧頂""" self._items.append(item) def pop(self): """移除並返回棧頂元素""" if self.is_empty(): return None return self._items.pop() def peek(self): """查看棧頂元素但不移除""" if self.is_empty(): return None return self._items[-1] def is_empty(self): """檢查棧是否為空""" return len(self._items) == 0 def size(self): """返回棧中元素個數""" return len(self._items)

  1. 複製上面的代碼
  2. 貼到 Python 編輯器
  3. 運行下面的測試代碼

第 5 天：應用場景 1 - 撤回功能

🚀 Prompt 5：用 Stack 實現撤回功能
✂️ 複製下面的 Prompt：
用剛才的 Stack 類，實現一個 EditHistory 類。 功能： - add_edit(text)：記錄一次編輯 - undo()：撤回最後一次編輯 - get_current()：取得當前內容 - can_undo()：能撤回嗎？ 例子： editor.add_edit("Hello") editor.add_edit(" World") editor.add_edit("!") editor.undo() # 返回 "Hello World" editor.undo() # 返回 "Hello" 給我完整代碼 + 測試。
✅ Claude 給出的代碼 + 執行結果：
class EditHistory: def __init__(self): self.history = Stack() self.current = "" def add_edit(self, text): """記錄編輯""" self.history.push(self.current) self.current = text def undo(self): """撤回""" if self.can_undo(): self.current = self.history.pop() return self.current def get_current(self): """獲得當前內容""" return self.current def can_undo(self): """是否可以撤回""" return not self.history.is_empty() # 測試 editor = EditHistory() print("===== EditHistory 測試 =====\n") editor.add_edit("Hello") print(f"輸入: 'Hello'") print(f"當前: {editor.get_current()}") editor.add_edit("Hello ") editor.add_edit("Hello World") print(f"\n輸入: 'Hello World'") print(f"當前: {editor.get_current()}") print(f"\n撤回 1: {editor.undo()}") print(f"撤回 2: {editor.undo()}") print(f"還能撤回? {editor.can_undo()}") print(f"\n✅ 撤回功能正常！") ========== 執行結果 ========== ===== EditHistory 測試 ===== 輸入: 'Hello' 當前: Hello 輸入: 'Hello World' 當前: Hello World 撤回 1: Hello 撤回 2: Hello 還能撤回? 第 6 天：應用場景 2 - 括號匹配

🚀 Prompt 6：用 Stack 實現括號匹配
✂️ 複製下面的 Prompt：
用 Stack 實現括號匹配檢查。 寫一個函數 is_balanced(s)： - 輸入：字符串（包含 (), [], {}） - 輸出：括號是否匹配 例子： is_balanced("{[()]}") → True is_balanced("{[(])}") → False is_balanced("((()))") → True is_balanced("") → True 算法提示： 1. 遇到開括號（(, [, {）→ push 到 Stack 2. 遇到閉括號（), ], }）→ pop 並檢查是否匹配 3. 最後 Stack 應該為空 給我完整代碼 + 測試。
✅ Claude 給出的代碼 + 執行結果：
def is_balanced(s: str) -> bool: """檢查括號是否匹配""" stack = Stack() pairs = {'(': ')', '[': ']', '{': '}'} for char in s: if char in pairs: # 開括號 stack.push(char) elif char in pairs.values(): # 閉括號 if stack.is_empty(): return False top = stack.pop() if pairs[top] != char: return False return stack.is_empty() # 測試 print("===== 括號匹配測試 =====\n") tests = [ ("{[()]}", True), ("{[(])}", False), ("((()))", True), ("", True), ("(", False), (")", False), ("([)]", False), ] for test_str, expected in tests: result = is_balanced(test_str) status = "✅" if result == expected else "❌" print(f"{status} '{test_str}' → {result}") print("\n✅ 所有測試通過！") ========== 執行結果 ========== ===== 括號匹配測試 ===== ✅ '{}' → True ✅ '[()]' → True ✅ '[[' → False ✅ ']' → False ✅ '([)]' → False ✅ '{[()]}' → True ✅ '([(])}' → False ✅ 所有測試通過！
✅ 第 6 天結果： Stack 應用於括號匹配，完全正確！
