這跟 Queue 有什麼關係？

核心洞察：「圍成一圈輪流報數」＝「排隊，報完數不出局的人走到隊伍最後面重新排」。
這正好就是 Queue 的兩個操作：dequeue（出隊報數） 和 enqueue（沒中，回到隊尾）。
queue = [1, 2, 3, ..., n] # 所有人排成一列 while len(queue) > 1: for i in range(k - 1): queue.enqueue(queue.dequeue()) # 報數 1~k-1：出隊，再回到隊尾 out = queue.dequeue() # 報數第 k 個：出隊，直接淘汰 print(f"{out} 號出局") print(f"生還者是 {queue.dequeue()} 號")
為什麼不能用 List？ 用 list 模擬「回到隊尾」要做 lst.pop(0)，時間複雜度是 O(n)（所有元素往前搬一格）。
用 deque 的 popleft() 是 O(1)。n = 10 萬人時，兩者差距超過 1000 倍。

歷史故事

西元 67 年，猶太史學家 Flavius Josephus 和 40 名同伴被羅馬軍隊困在山洞裡。同伴決定集體自殺也不投降， 辦法是圍成一圈，每數到 3 的人就被殺死。約瑟夫不想死，他快速算出「第幾個位置會活到最後」， 悄悄站到那個位置 —— 最後他和另一人活了下來，並向羅馬投降。

這就是為什麼這個問題叫「約瑟夫問題」。你剛剛玩的，就是他當年在山洞裡算的東西。

進階：k = 2 時的神奇規律

把 k 設成 2，然後試試不同的 n，把生還者記下來：

n（人數）生還者位置觀察
11n = 2⁰ + 0
21n = 2¹ + 0
33n = 2¹ + 1
41n = 2² + 0
53n = 2² + 1
65n = 2² + 2
77n = 2² + 3
81n = 2³ + 0
公式：把 n 寫成 n = 2m + L（其中 0 ≤ L < 2m），生還者就是 2L + 1。
更酷的寫法：把 n 轉成二進位，然後把最高位的 1 搬到最右邊，就是答案。
例：n = 13 = 1101₂ → 1011₂ = 11 → 第 11 號生還。用上面的遊戲驗證看看！
