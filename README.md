# 資料結構遊戲場

把每一個資料結構做成可以一步一步走、還能自己猜下一步的互動教材。
純 HTML / CSS / JavaScript，**沒有任何相依套件，離線可用**。

## 怎麼用

雙擊 `index.html` 即可。所有連結都是相對路徑，整個資料夾複製到隨身碟、
或直接上傳到任何靜態網站空間（GitHub Pages、Netlify、Cloudflare Pages）都能跑。

> 上傳前建議把外層資料夾改成英文名（例如 `ds-games`），
> 中文資料夾名在網址上會變成一長串編碼。裡面的檔名已經都是英文。

## 檔案結構

```
資料結構/
├─ index.html                      課程地圖（首頁，連到所有遊戲）
├─ assets/
│  └─ site.css                     全站設計系統 ← 改配色、改共用元件都在這裡
├─ games/
│  ├─ _template.html               新遊戲的空白模板（含四段架構與註解）
│  ├─ 01-bracket-matching.html     括號堆疊闖關
│  ├─ 02-expression-calculator.html 運算式計算機（中序→後序→求值）
│  ├─ 03-monotonic-stack.html      單調堆疊（柱狀圖最大矩形 / 每日溫度）
│  ├─ 04-call-stack.html           呼叫堆疊（階乘 / 費氏 / 河內塔）
│  ├─ 05-hanoi.html                河內塔（可互動 + 遞迴自動示範）
│  ├─ 06-josephus.html             約瑟夫問題
│  ├─ 07-bfs-maze.html             迷宮 BFS 對 DFS
│  └─ 08-flood-fill.html           油漆桶填充（Flood Fill）
└─ README.md
```

## 每一頁的固定架構

所有教學頁一律四段，順序不變：

| 段 | 標題 | 內容 |
|---|---|---|
| **01** | 怎麼玩・你會學到什麼 | 左欄操作方式，右欄這一關要建立的觀念清單 |
| **02** | 開始玩 | 遊戲本體：逐步演示，多數關卡還有闖關／自由操作模式。**遊戲正下方就是它跑的完整程式**（含所有基底條件），玩到哪對照到哪 |
| **03** | 這個功能是怎麼做到的 | 問題定義 → 破除錯誤直覺 → 關鍵觀察 → 演算法 → 邊界情況 → 手算表 → 複雜度 → 常見誤解 |
| **04** | 程式架構與說明 | 設計決定 → 模組分工 → 資料流圖 → 核心資料 → 怎麼改 → **給 AI 的 Prompt**。只講流程與架構，不逐行拆解 |

## 新增一個遊戲

1. 複製 `games/_template.html` → `games/09-你的遊戲.html`
2. 照著檔案裡的註解，把四段填滿（模板已標好每一塊該寫什麼）
3. 在 `index.html` 找到對應的卡片，把 `<div class="card is-soon">`
   改成 `<a class="card is-live" href="games/09-你的遊戲.html">`
   （結束標籤 `</div>` 也要改成 `</a>`），並加上一行 `<span class="go">開始玩 →</span>`

首頁的「已完成 / 規劃中」數字會自動重算，不用手動改。

## 程式寫法的共同約定

每個遊戲的 JavaScript 都照同一個骨架，換一個遊戲也不用重新學：

```
1. 常數     LEVELS / PRESETS（關卡）、CODE（虛擬碼）
2. 狀態     全站唯一一份狀態物件或一組模組層變數
3. 資料層   buildSteps(input) → 一次算完整個過程，回傳步驟陣列
4. 畫面層   paintXxx() / renderXxx()：只讀目前那一步，畫自己那一塊
5. render() 把所有畫面函式叫過一遍
6. 導覽     goto_() / next() / prev() / startPlay()
7. 闖關     renderQuiz() / answerQuiz()
8. 載入     loadLevel() / setMode()
9. 事件綁定（全部用 addEventListener，HTML 裡沒有 onclick）
10. 啟動
```

### 兩種播放架構，各有適用場合

| 架構 | 用在哪些關 | 優點 | 代價 |
|---|---|---|---|
| **先算完，再播放**<br>`buildSteps()` 產生步驟陣列 | 01、02、03、04 | 前進後退只是陣列索引加減一；畫面函式是純函式 | 每步存快照，記憶體高 |
| **邊算邊播**<br>直接改動狀態再重畫 | 05、06、07、08 | 程式短、跟真實實作長得一樣 | 不能倒退，只能重來 |

需要學生反覆倒帶的關卡用前者，參數可調、重跑便宜的關卡用後者。
每一頁的第 04 段都會誠實說明自己用的是哪一種、為什麼。

## 教材程式語言

頁面上給學生看的演算法程式一律用 **C/C++（STL）** 呈現 ——
`std::stack`、`std::queue`、`std::deque`，給 AI 的 Prompt 也是要求 C++ 實作。
遊戲互動本身是 JavaScript；「演算法」和「畫面包裝」的分界在每頁第 04 段有說明。

## 改外觀

所有顏色、字體、間距、共用元件都在 `assets/site.css`。
改一次，首頁和所有遊戲頁同時更新。深色模式已經跟著系統設定處理好了。

各遊戲頁的 `<style>` 只放「這一關獨有的視覺」——
圓圈、迷宮格、柱狀圖、塔柱、字元帶之類的東西。
